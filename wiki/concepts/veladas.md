# Veladas

## Definición

**Veladas** es el término empleado en la documentación de origen para designar los turnos nocturnos o de cobertura en los que se asignan roles específicos al personal. Constituye una estructura organizativa de turnos dentro de la operación del NOC, en la que cada rol delimita responsabilidades concretas durante el período de cobertura.

## Características clave

- Designa un **turno de cobertura**, habitualmente nocturno, dentro de la operación del centro de operaciones de red (NOC).
- Se organiza mediante **roles asignados**: la fuente menciona explícitamente los "Roles en Veladas".
- Entre los roles identificados se incluyen la **gestión de CNT**, las **Pruebas L3** y las **Tareas sisrred / Ventanas de Mantenimiento**.
- Cada rol define las **responsabilidades del personal** durante la velada, evitando ambigüedad en la asignación de tareas.
- Funciona como **unidad organizativa de turnos**, no como una herramienta o sistema técnico.

## Aplicaciones

- **Planificación de turnos**: distribuir la cobertura nocturna del NOC entre el personal disponible según los roles definidos.
- **Asignación de responsabilidades**: determinar quién ejecuta las Pruebas L3, quién gestiona CNT y quién atiende las tareas sisrred durante la velada.
- **Coordinación con ventanas de mantenimiento**: sincronizar la ejecución de cambios planificados con los turnos de velada que cuentan con cobertura.
- **Trazabilidad operativa**: registrar qué rol atendió cada actividad durante el turno, facilitando la auditoría y el relevo entre turnos.
- **Onboarding y capacitación**: usar la estructura de roles como base para formar al personal nuevo en las responsabilidades de cada velada.
