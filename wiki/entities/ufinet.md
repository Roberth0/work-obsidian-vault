# UFINET

## Descripción

UFINET es un operador de infraestructura de telecomunicaciones que forma parte de las relaciones de interconexión del [[Backbone]] gestionado por [[Telconet]], junto con otros operadores como TIGO y Fastly. La interacción entre ambas partes se centra en la gestión de incidencias sobre los enlaces de interconexión.

Como vía formal para el reporte y seguimiento de dichas incidencias, UFINET dispone de un nuevo portal web de generación de tickets accesible en `https://gestionticketing.ufinet.com/auth`, para el cual se documentan credenciales de acceso corporativo. El uso de este portal constituye el canal oficial para notificar y dar trazabilidad a las incidencias que afectan a los enlaces con este operador.

El documento fuente recoge tanto los datos de acceso como la existencia de este portal, lo que convierte a UFINET en un actor relevante dentro de los procedimientos operativos de [[Telconet]] para la gestión de su red troncal.
